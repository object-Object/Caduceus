# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## `0.3.0+1.20.1` - 2026-07-25

### Additions

- New patterns:
  - Elbrus' Gambit: Casts a list of patterns.
  - Prometheus' Gambit: Jumps to an index in that list of patterns, similar to `goto`.

## `0.2.1+1.20.1` - 2026-01-15

### Changes

- Updated zh_cn translations, by ChuijkYahus in [#6](https://github.com/object-Object/Caduceus/pull/6).

## `0.2.0+1.20.1` - 2026-01-04

### Additions

- New patterns:
  - Arke's Gambit II: `prompt-at`
  - Thetis' Gambit II: `control-at`

### Changes

- New icon by SamsTheNerd!
- Updated zh_cn translations, by ChuijkYahus in [#4](https://github.com/object-Object/Caduceus/pull/4).

- Fixed empty continuations having a size of 0.
